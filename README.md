# Chell:
Working on a unix- like shell in C (Chell)

## About:
Chell is a simple shell that excutes system commands using Linux syscalls
It is build to understand on how shell works in low level

## Features:
Commands excute using Fork() and execvp() 
Argument parsing using 'strtok'
basic loop for a shell
Has an exit command 

## How to compile
- Requires Gcc
- 'gcc chell.c -o chell'
